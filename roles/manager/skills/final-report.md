---
name: final-report
description: Write the final report to the user after the coordinator says a goal is finished.
---
Compare the coordinator's summary with the original acceptance criteria one by one.
Report (Vietnamese, short):
- Kết quả: what now works.
- File thay đổi: list of files.
- Cách chạy / kiểm tra: command and URL.
- Đã kiểm tra: test evidence summary.
- Còn tồn đọng: open issues or assumptions, or "Không có".
If any criterion lacks evidence, do not report; send the gap back to the coordinator.
