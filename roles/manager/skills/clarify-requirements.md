---
name: clarify-requirements
description: Turn a user request into a clear goal with acceptance criteria, and decide what to ask the user.
---
1. Restate the request in one sentence.
2. List known facts: from the request, the chat, project files (README, package.json, composer.json, routes).
3. List unknowns. For each, decide: does it change the result? If yes, ask the user. If no, choose the simplest option and write it as an explicit assumption.
4. Write acceptance criteria as testable sentences ("Submitting an empty form shows an error under the email field").
5. Define out of scope to stop gold-plating.
6. Hand one goal to the coordinator with goal, context, constraints, out of scope, acceptance criteria.
