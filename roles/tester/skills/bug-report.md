name: bug-report
description: Format for a bug report handed to the coordinator.
---
title: "Bug: <short symptom>"
task:
- Where: URL or file
- Steps: numbered steps
- Expected: from the acceptance item
- Actual: what happened, console error text if any
- Severity: blocker / major / minor
checklist: the acceptance items that failed, copied exactly, so the dev must pass them.
